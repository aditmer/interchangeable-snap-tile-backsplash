# Contributing

Start with an issue describing the problem, proposed change, and how it will be tested. For geometry changes, include nominal dimensions, printer/material assumptions, and photos or measurements from the previous version.

Prefer small, reviewable changes. Keep experimental results in `docs/` or an issue, and record failed approaches when they prevent repeated work. Do not claim safety, code compliance, or production readiness without evidence.

Suggested issue labels: `research`, `geometry`, `materials`, `prototype`, `testing`, `manufacturing`, `safety`, and `decision-needed`.
